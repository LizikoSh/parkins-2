# Паркінс

Статичний українськомовний інформаційний сайт про життя з хворобою Паркінсона.

## Файли

- `index.html` — головна сторінка, швидкі маршрути та пошук по темах.
- `first-steps.html` — перші кроки після встановлення діагнозу.
- `understand.html` — основне про хворобу, симптоми, діагностику та зміни впродовж дня.
- `treatment.html` — складові лікування та команда допомоги.
- `daily-life.html` — побут, сон, падіння, завмирання, робота, водіння тощо.
- `movement.html` — рух, безпека та орієнтири фізичної активності.
- `nutrition.html` — харчування, вода, вага, травлення та ковтання.
- `emotional-support.html` — настрій, тривога, апатія, втома і звернення по допомогу.
- `doctor-visit.html` — підготовка до консультації та пам’ятка для друку.
- `relatives.html` — матеріали для близьких.
- `support-ukraine.html` — офіційні українські джерела допомоги.
- `about.html` — про сайт, редакційний підхід, джерела та конфіденційність.
- `styles.css` — усі стилі сайту.
- `script.js` — навігація, доступність, пошук, фільтри, модальні вікна та друк.

## Локальний запуск

Достатньо відкрити `index.html` у браузері. Для перевірки як на Vercel/GitHub Pages зручніше запустити простий локальний сервер, наприклад:

```bash
python -m http.server 8000
```

Після цього відкрити `http://localhost:8000/`.

## Важлива примітка

Сайт має інформаційний характер і не замінює консультацію лікаря. Для повноцінного медичного інформаційного ресурсу бажано організувати окрему професійну медичну верифікацію контенту та регулярний перегляд сторінок із державними програмами й контактною інформацією.
